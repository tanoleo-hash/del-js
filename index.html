Build Desktop-Like Web Apps Without Build Tools

DEL.js (Desktop Easy Language) is an ultra-lightweight DSL transpiler. Write components, Tailwind CSS styles, persistent SQLite WASM queries, and native JS inside a single script tag.

Quick CDN Install 
<script src="https://cdn.jsdelivr.net/gh/tanoleo-hash/del-js@main/del.js"></script>
⚡

Zero Configuration

No npm, Webpack, or Vite needed. Drop the CDN link into any HTML document and run directly in the browser.

🎨

Tailwind Integrated

Define UI styles using @apply and custom CSS directly inside DEL Style blocks.

💾

SQLite WASM Persistence

Built-in SQL support powered by sql.js and LocalStorage state preservation across app restarts.

🌙

Persistent Theme Engine

Automatic Dark/Light mode state memory using LocalStorage with a single function call.

💻

Native JS Blocks

Write standard JavaScript inside Script { ... } blocks without parser limitations.

📦

Desktop App Ready

Package instantly into native Windows .exe apps via Edge App Mode or Neutralino.js.

Getting Started

Include the CDN links inside your HTML header and place your application logic inside a <script type="text/del"> block. 

<script src="https://cdn.tailwindcss.com"></script>
<script src="https://cdn.jsdelivr.net/gh/tanoleo-hash/del-js@main/del.js"></script>

<script type="text/del">
  Window "My App", 400, 500
  Text "Hello World from DEL.js"
</script>

UI Syntax Cheatsheet

Directive Description Syntax Example
Window Sets window title and bounds Window "App Title", width, height
Text Renders text element Text "Hello World"
Input Input field bound to variable Input "Placeholder" -> varName
Button Clickable button with handler Button "Label" -> { action() }
Style Applies custom CSS or Tailwind Style Window { @apply p-4; }
Database Initializes persistent SQLite DB Database "app.db"
Table Creates SQL schema Table "users" (id INT, name TEXT)
Save Inserts data into table Save "users" (name) -> "Aung"
Script Native JS block Script { console.log('OK'); }

Styling with Tailwind

Use DEL's Style blocks to map element selectors directly to Tailwind CSS utility classes. 

Style Button {
  @apply w-full bg-indigo-600 hover:bg-indigo-500 text-white font-semibold py-3 px-6 rounded-lg shadow transition-all;
}

Method 1 Windows .EXE via Edge App Mode (Zero Dependency)

  1. Create Batch Script: Inside your DEL project directory, create a file named Run_App.bat:
    @echo off start msedge --app="%~dp0index.html" --window-size=450,550
  2. Convert .BAT to .EXE: Use a free utility like BAT to EXE Converter or Windows built-in iexpress to convert your batch file into an invisible application executable with a custom app icon.
